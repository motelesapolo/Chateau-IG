# Material del hotel 📸

Aquí van las **fotos y videos reales** de Le Chateau. Claude los usa en las publicaciones
(sobre todo cuando se muestran las habitaciones: nunca se usan imágenes de IA para eso).

## Dónde va cada cosa
| Carpeta | Qué subir |
|---|---|
| `habitaciones/simple/` | Habitaciones Simple |
| `habitaciones/vip/` | Habitaciones VIP |
| `habitaciones/jacuzzi/` | Habitaciones Jacuzzi (el jacuzzi con espuma, la tina, la luz) |
| `espacios/` | Fachada, recepción, pasillos, estacionamiento, detalles del edificio |
| `servicios/` | Cortesía (pisco sour, mango sour), pizzas, bar, desayuno, toallas, amenidades |
| `otros/` | Cualquier otra cosa (fechas especiales, decoraciones, etc.) |

## Cómo subir (desde el computador)
1. Entra a la carpeta que corresponda aquí en GitHub (por ejemplo `habitaciones` → `jacuzzi`).
2. Arriba a la derecha: **Add file → Upload files**.
3. Arrastra las fotos o videos (hasta 100 por vez, máximo 25 MB cada uno) → **Commit changes**.

En unos minutos GitHub los deja listos solo: convierte fotos del iPhone (HEIC) a JPG, achica lo pesado
y **borra los metadatos** (ubicación GPS, modelo del celular). No hace falta preparar nada.

¿El video pesa más de 25 MB o estás en el celular? Mándalo por el chat a Claude y él lo sube.

## Consejos para que se vean bien
- **Vertical** (como una historia) siempre que puedas. Fotos con buena luz: abre cortinas, enciende luces cálidas.
- Videos cortos de 5 a 15 segundos, moviendo el celular lento. Mejor varios clips cortos que uno largo.
- Habitaciones ordenadas y limpias: cama hecha, toallas dobladas, sin objetos personales.

## ⚠️ No subir
- **Personas reconocibles** (clientes, personal), aunque sea de espalda o en un reflejo.
- **Patentes de autos**, documentos, pantallas con datos, cámaras de seguridad.
- Nada íntimo o sugerente: la cuenta vende descanso y desconexión.

Este repositorio es **público**: todo lo que subas aquí se puede ver en internet.
